# results/

Everything here is regenerated by `python run_all.py` (see the root `README.md`). Figure N of the report is `figures/figNN_*.png`.

## Text results

| File | Written by | Contents |
|---|---|---|
| `eda_results.txt` | `eda_analysis.py` | every EDA result and hypothesis test in plain words, with its denominator; success-criteria check (section 10) |
| `pca_results.txt` | `feature_extraction_pca.py` | PCA on the final features and the keep / reject decision |
| `supplementary_results.txt` | `supplementary_analysis.py` | dataset composition (section 0), population profile, adjusted odds ratios, regional split, MI check, survey design, criterion-5 assertion |
